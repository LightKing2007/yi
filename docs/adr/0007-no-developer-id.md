# 0007 暂不申请 Apple Developer ID 签名

| 项目 | 内容 |
|---|---|
| 状态 | 接受 |
| 日期 | 2026-10-13 |
| 决定者 | 项目所有者 |
| 相关 | 整改项 P2-20（审计发现 A-14）；#126；SEC-071；决策 D8 |

## 1 背景

1.1 macOS 版以临时签名（`identity: "-"`）打包，开启了强化运行时。权限声明 `build-res/entitlements.mac.plist` 中，除 V8 即时编译所需的 `allow-jit` 外，还声明了 `allow-unsigned-executable-memory` 与 `disable-library-validation`（A-14）。

1.2 审计建议在取得 Developer ID 签名后收紧这两项。签名与公证需要付费的 Apple 开发者账号，每年 99 美元。

## 2 决策

2.1 暂不申请 Apple 开发者账号，macOS 版继续以临时签名发布，权限声明保持现状。

2.2 整改项 P2-20 除 A-14 外均已完成（#126），A-14 记为暂不实施。

## 3 备选方案

| 方案 | 不采用的原因 |
|---|---|
| 申请开发者账号，签名、公证并收紧权限声明 | 每年 99 美元；游戏只在小范围内分发（决策 D7） |
| 不签名而直接收紧权限声明 | 补录时整理，当时未讨论：临时签名下改动这两项须在 macOS 实机上验证游戏仍能启动，收益有限 |

## 4 后果

4.1 macOS 首次打开时仍有未公证的提示，发布说明与下载页面须继续写明打开方法（SEC-071）。

4.2 两项较宽的权限声明保留；游戏只加载 asar 中自身的代码（SEC-035），并已启用 Electron Fuses 的 asar 完整性校验（SEC-033），影响有限。

4.3 以后面向更多玩家发行时，应重新评估签名与公证，届时一并收紧权限声明。
