# 0011 公开 UID 采用八位 Base32，绑定邮箱按账号存续期保留

| 项目 | 内容 |
|---|---|
| 状态 | 接受 |
| 日期 | 2026-10-30（America/Los_Angeles） |
| 决定者 | 项目所有者（本次会话明确选择八位字母数字 UID、账号存续期间保留邮箱）；验证码保护为存储设计的工程细化 |
| 相关 | [存储方向 0010](0010-account-storage.md)、[阶段 6、7 设计](../plan/phase6-7.md)、DAT-070、DAT-074 |

## 1 背景

1.1 项目所有者要求系统分配不可更改的 UID，末位有校验，不使用唯一雅号区分玩家。日期加随机数的十七位方案、十位纯数字方案均偏长，最终选择八位字母数字。

1.2 原 DAT-074 对所有 L3 数据设置一百八十日上限，会迫使长期使用的账号清除绑定邮箱。项目所有者明确同意：绑定邮箱在账号存续期间保留，用于登录、验证和密码重置；注销时限期清除，过期验证码和未完成注册资料及时清理。

1.3 短数字验证码即使普通 SHA-256 散列，也可在数据库泄露后被离线枚举。设计采用独立密钥的 HMAC-SHA-256 凭据保护，需与 DAT-070 同步，不降低密码存储强度。

## 2 决策

2.1 公开 UID 是八字符文本，七位密码学随机数据加一位 Luhn mod 32 校验，字母表为 `0123456789ABCDEFGHJKMNPQRSTVWXYZ`。排除 I、L、O，不含日期、生日、地区或邮箱；规范值大写，输入不区分大小写，允许四位之间的单个连字符。显示示例为 `7KM4-P9D2`，存储为 `7KM4P9D2`。

2.2 由服务端生成；数据库唯一索引及有限碰撞重试保证唯一，不允许客户端选择或修改。校验只发现录入错误，不是登录或所有权凭据。数据库内部整数主键与历史设备标识保持独立。

2.3 绑定邮箱密文及邮箱查找标识按 L3 管理，在账号存续且用途仍为登录、验证与重置时保留。账号注销后十五日内清除邮箱密文、查找标识和认证凭据，并匿名化对局中的个人展示信息；不能通过继续保留邮箱查找标识变相保留已注销邮箱。

2.4 未完成注册和验证码资料按挑战有效期及发送状态设置更短清理期限；其余 L3 仍不超过一百八十日。不可变备份按既定保留策略自然淘汰，不得恢复已执行的删除或匿名化：恢复流程须重放单独保存的删除记录后才开放服务。真实注销流程与备份恢复的验收属于后续实施，本记录不声称已经完成。

2.5 高熵会话令牌仅存 SHA-256 散列；短邮箱验证码只存独立密钥的 HMAC-SHA-256 凭据，消息编码绑定用途、挑战编号、邮箱查找标识与验证码。验证码密钥不与数据库、邮箱加密密钥或邮箱查找密钥共存复用；错误次数、到期、单次消费及发信预算仍须分别校验。原密码 scrypt 规则不变。

## 3 备选方案

| 方案 | 处理 |
|---|---|
| 十七位日期加数字 | 用户认为过长，未采用 |
| 十位纯数字 | 用户仍希望更短并允许字母，未采用 |
| 无校验位的短标识 | 不满足末位校验要求 |
| 绑定邮箱一百八十日强制删除 | 用户选择账号存续期间保留 |
| 六位验证码普通 SHA-256 | 无法有效防止数据库泄露后的离线枚举，改为带独立密钥保护 |

## 4 后果

4.1 标识更短且不公开注册日期；输入需要字母。客户端、服务端共用纯校验模块，随机生成只发生于服务端。

4.2 八位标识不是秘密或安全令牌；随机生成仍可能碰撞，必须由持久化唯一约束和有界重试裁决，不承诺随机数绝对不重复。

4.3 邮箱继续用于既定账号目的，隐私说明、注销、密钥备份及恢复程序均需同步。验证码凭据引入额外独立密钥与轮换责任，不代替在线限速或机器人防护。
