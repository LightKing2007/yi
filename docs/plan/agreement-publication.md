# 官网文书草案的后续补齐事项

2026-10-31，根据项目所有者提供的三份 Markdown 草案整理。网站仍为草案展示，不作为现行联机的同意依据；本记录不授权发版或部署。

正文保存在 `server/legal/`，通过构建时的文本导入嵌入服务端。文件末尾的编辑核对清单不属于对外正文，原件保留不改写。

已补充个人开发者王耀（LightKing）的身份、现行与未来账号功能的边界、雅号及 UID、注销后十五日清除的拟定规则、站内文书链接与公开反馈注意事项。未将仓库日志模板的九十日配置当作生产实测结论。

正式版本前仍需完成：

- 确定专用联系邮箱、联系地址、个人信息与未成年人事项的有效私密渠道。
- 确定邮件提供者、实际托管区域、委托处理安排及涉及的跨境数据流。
- 核实运行、安全及访问日志的实际类别和法定留存要求。
- 明确历史验证码、过期会话、限流、棋谱、段位和同意记录的具体清理周期。
- 核实加密异地备份轮换期限，验收删除记录重放及恢复后防止已注销账号恢复可用的机制。
- 完成账号注销、权利请求、违规通知与申诉流程，确认答复时限。
- 完成依法适用的实名、防沉迷、监护人同意、监护关系核验及适龄提示机制。邮箱验证不能代替实名验证。
- 在功能开放前提供明确的同意与拒绝入口，记录准确版本；本页草案版本不能直接用于正式同意记录。
- 补充实际棋类、排位、重连和结算规则入口，正式收费前另行确定价格、退款及停止运营安排。
- 根据实际处理活动完成必要评估和正式文本复核，确定生效日期与历史版本查询方式。
