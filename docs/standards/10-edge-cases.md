# 弈 · 极端与边界情况防御规范

| 项目 | 内容 |
|---|---|
| 所属 | 弈 · 工程规范（YI-STD-001），总则见 [00-general.md](00-general.md) |
| 文件版本 | 1.1 |
| 修订日期 | 2026-10-02 |
| 规则前缀 | `EDGE` |

参考：ISO/IEC 25010:2023 可靠性（容错性、可恢复性）；ISO 22301:2019；OWASP ASVS 5.0；GB/T 22239—2019。

## 1 总体要求

| 编号 | 等级 | 规定 | 现状 |
|---|---|---|---|
| EDGE-001 | C | 每个新功能的 PR 必须在说明中逐项回答本文件第 2 节至第 9 节中适用的场景：如何检测、如何处理、如何降级、如何测试；不适用的场景必须写明“不适用”及理由 | 未满足 |
| EDGE-002 | A | 降级的统一原则：数据层“故障即停”（宁可停止服务也不写坏数据）；交互层“故障可用”（宁可关闭某项功能也不让游戏崩溃）；单机功能严禁依赖网络 | 部分满足 |
| EDGE-003 | A | 每个降级状态必须对玩家可见（提示文字），并对维护者可见（`warn` 及以上日志） | 部分满足 |

## 2 高并发与资源耗尽

| 场景 | 检测 | 必须的处理 | 降级 | 验证 |
|---|---|---|---|---|
| 玩家数达到 2048 上限 | `players.size` | 下发 `server.full`（E2）后以 1013 关闭 | 客户端显示“服务器繁忙”，按 API-050 退避 | 集成测试 |
| 房间数达到 1024 上限 | `rooms.size` | 开房下发 `server.full`；匹配队列照常 | 只允许匹配与排位 | 现有测试 |
| 服务器重启后重连风暴 | 每秒新连接数 | 客户端带抖动退避（API-050）；服务端每 IP 每分钟 ≤ 30 次新连接（API-041） | 超出者以 1013 关闭 | 压测（P2-07） |
| 事件循环阻塞 | 事件循环延迟 p99 | 延迟 ≥ 200 毫秒持续 30 秒时，拒绝新的 `hello`（1013），已有对局照常 | 只服务已有对局 | 压测 |
| 内存增长 | 常驻内存 | systemd `MemoryMax=512M` 兜底；达到 80% 告警 | 被系统终止后 3 秒自动重启，客户端重连 | 压测 |
| 文件描述符耗尽 | `EMFILE` 错误 | `LimitNOFILE=65536`；出现 `EMFILE` 时写 `error` 并拒绝新连接 | 只服务已有连接 | 人工审查 |
| 下载占满带宽 | 下载并发数 | 每 IP ≤ 2、全服 ≤ 8（现有）；超出返回 503 与 `Retry-After: 30` | 联机不受影响 | 现有测试 |
| 单局动作记录过长 | `acts.length` | 上限 4096（现有），超出不再记录并写 `warn` | 重连时以当前局面同步（v4 `sync`） | 单元测试 |
| 磁盘写满 | 写盘异常 `ENOSPC` | DAT-052：保留内存、退避重试、告警 | 段位暂存内存，恢复后补写 | 单元测试（假文件系统） |

## 3 网络抖动

| 场景 | 检测 | 必须的处理 | 降级 | 验证 |
|---|---|---|---|---|
| 半开连接（对方已断，本方未察觉） | 服务端 `IDLE_SECS`、客户端 `SILENT_SECS` | 判定断开，进入重连（现有） | 对局保留 `GRACE_SECS` | 现有测试 |
| 高延迟（RTT ≥ 1 秒） | 心跳往返时间 | 客户端显示网络延迟指示；计时以服务端为准 | 无 | 人工测试 |
| 丢包导致消息丢失 | v4 `seq` 跳号 | 请求 `resync`，以完整状态覆盖本地 | 无 | 集成测试 |
| 消息重复（重发、双击） | v4 `seq` 重复 | 服务端幂等忽略（API-052）；客户端发出落子后在确认前锁定输入 | 无 | 集成测试 |
| 重连时对局已结束 | 重连后收到 `over` | 显示结果与段位变化（现有） | 无 | 现有测试 |
| 重连时服务器已重启 | `resumeFailed` | 退出对局并提示（现有） | 返回联机页面 | 现有测试 |
| 双方同时掉线 | 两方 `offAt` | 暂停计时；任一方回来后等待另一方，`GRACE_SECS` 后判先掉线方负 | 无 | 单元测试 |
| 客户端时钟被修改 | 不检测 | 计时与超时只以服务端单调时钟为准（API-053） | 无 | 人工审查 |

## 4 脏数据

| 场景 | 检测 | 必须的处理 | 降级 | 验证 |
|---|---|---|---|---|
| 段位存档损坏 | JSON 解析失败 | 拒绝启动，保留原文件，退出码 65（DAT-050） | 由维护者从 `.prev` 或备份恢复 | 单元测试 |
| 存档字段缺失或类型错误 | 逐条校验 | 该条使用默认值并写 `warn`，严禁整体丢弃 | 该玩家段位重置为默认，原值保留在 `.corrupt` | 单元测试 |
| 本地设置损坏 | 解析或校验失败 | DAT-080、DAT-081 | 使用默认设置 | 单元测试 |
| 非法协议消息 | `parseC2S` | API-015 | 丢弃并累计违规 | 单元测试（每种非法形式至少 1 例） |
| 数值为 `NaN`、`Infinity`、小数、负零 | `Number.isInteger` | 按非法消息处理 | 同上 | 单元测试 |
| 非法 UTF-8 帧 | `ws` 库 | 以 1007 关闭 | 无 | 集成测试 |
| 棋谱回放与实际局面不一致 | v4 局面散列 | 以服务端完整状态重建 | 无 | 集成测试 |
| 数据库约束被违反 | SQLite 约束异常 | 回滚事务，写 `error`，向客户端下发 E5 | 本局不计段位，下发说明 | 单元测试 |

## 5 恶意攻击

| 场景 | 检测 | 必须的处理 | 降级 | 验证 |
|---|---|---|---|---|
| 消息洪泛 | 令牌桶（API-043） | 丢弃并累计违规，达到上限以 1008 断开（API-045） | 无 | 单元测试 |
| 遍历房号 | 加入失败计数 | 每分钟 5 次后暂停（现有）；房号空间 10^4，房间存活 ≤ 30 分钟未开局即关闭 | 无 | 现有测试 |
| Slowloris 慢速请求 | HTTP 超时（API-047） | 超时断开 | 无 | 集成测试 |
| 下载路径穿越 | 文件名白名单正则 | 不匹配即 404（现有） | 无 | 现有测试 |
| 昵称伪造（双向控制符、零宽字符） | 字符类别 | API-014 清洗 | 无 | 单元测试（含 U+202E、U+200B） |
| 重连令牌窃取 | 不可检测（明文期间） | SEC-020 每次重连轮换令牌，缩短窃取后的可用时间；3.0 起 TLS | 无 | 单元测试 |
| 小号刷分 | 阶段 8 自动规则 | 设备散列关联、同 IP 对局不计分 | 冻结排位 | 阶段 8 测试 |
| SSH 爆破 | fail2ban | SEC-040 至 SEC-042 | 无 | 季度审计 |
| 安装程序被替换 | 校验和 | SEC-070、OPS-031 | 无 | 发布检查清单 |
| 恶意构造的超长昵称、超大消息 | 长度检查 | API-002、API-014 | 无 | 单元测试 |

## 6 版本兼容

| 场景 | 检测 | 必须的处理 | 降级 | 验证 |
|---|---|---|---|---|
| 旧客户端连接新服务端 | `hello.v` | 在支持范围内照常服务；超出范围下发 `proto.version-mismatch` 与下载地址，以 4000 关闭（API-004） | 旧客户端仍可单机游戏 | 集成测试 |
| 新客户端连接旧服务端 | 收到未知消息类型 | 客户端忽略未知消息并写 `warn`，严禁崩溃 | 功能按旧协议运行 | 单元测试 |
| 新版本读到旧本地设置 | `v` 字段 | 按版本迁移，迁移后写回 | 迁移失败按 DAT-081 | 单元测试 |
| 旧版本读到新本地设置（降级安装） | `v` 高于支持 | 只读使用可识别的字段，严禁写回（VER-012） | 使用默认值 | 单元测试 |
| 数据库结构高于程序支持 | `schema_version` | 拒绝启动（VER-012） | 回滚到匹配的版本 | 单元测试 |
| 上线后发现严重问题 | OPS-047 条件 | 10 分钟内回滚（OPS-044） | 无 | 季度演练 |

## 7 多语言与国际化

| 场景 | 检测 | 必须的处理 | 降级 | 验证 |
|---|---|---|---|---|
| 译文缺失 | CI 静态扫描（I18N-010） | 阻断合并 | 运行时回退中文原文 | CI |
| 英文过长溢出 | 长度测试（I18N-020） | 阻断合并 | `Fit` 缩小字号，最小 10 像素 | CI + 人工查看 |
| 系统无中文字体 | 不检测 | 内置思源字体子集（现有） | 子集外的生僻字回退系统字体 | Linux 截图验证 |
| 昵称含表情、组合字符 | 字素计数 | 按字素截断（I18N-030） | 无 | 单元测试 |
| 昵称为空或全为被清洗字符 | 清洗结果为空 | 使用默认昵称“棋手” | 无 | 现有测试 |
| 服务端发来客户端没有译文的文本（v3） | 查表未命中 | 原样显示中文 | 无 | 现有行为 |

## 8 平台与运行环境

| 场景 | 检测 | 必须的处理 | 降级 | 验证 |
|---|---|---|---|---|
| WebGL2 不可用 | 创建上下文失败 | 显示“需要支持 WebGL2 的显卡”提示页 | 无法游戏，但不崩溃 | 人工测试 |
| WebGL 上下文丢失 | `webglcontextlost` | 自动恢复（现有） | 恢复失败时提示重启 | 现有功能 |
| 无独立显卡 | 软件渲染 | 允许以 SwiftShader 运行 | 帧率下降，功能完整 | Windows CI 截图 |
| 音频设备不可用 | `AudioContext` 异常 | 静音运行 | 无声音 | 人工测试 |
| 窗口小于最小尺寸 | 窗口尺寸 | 最小 800×600（现有），布局在最小尺寸下无重叠 | 无 | 截图验证 |
| macOS 拦截未公证应用 | 无法检测 | 发布说明与下载页面写明打开方法（现有） | 无 | 发布检查清单 |
| 用户数据目录不可写 | 写入异常 | 设置保存失败不影响运行（DAT-082）；日志写入失败静默跳过 | 设置不保存 | 单元测试 |

## 9 部署与人为失误

| 场景 | 检测 | 必须的处理 | 降级 | 验证 |
|---|---|---|---|---|
| 上传中断 | 上线脚本退出码 | 先传 `.incoming/` 再移动（现有）；重新执行上线脚本必须幂等 | 下载页面保持旧版本 | 人工演练 |
| 两人同时上线 | 部署锁（OPS-041） | 后者等待或中止 | 无 | 人工演练 |
| 误上线旧版本 | 版本比较（OPS-042） | 必须显式确认 | 无 | 单元测试 |
| GitHub 不可用 | 下载失败 | 上线中止，线上不变 | 推迟上线 | 无 |
| 直接推送 `main` | 钩子 + CI 来源校验（OPS-005、OPS-006） | 阻断或告警 | 无 | CI |
| 提交了密钥 | gitleaks（SEC-050） | 阻断；已推送的必须在 24 小时内轮换密钥并清理历史 | 无 | CI |
| 误删生产数据 | 不可检测 | 从备份恢复（DAT-060） | 无 | 季度演练 |
